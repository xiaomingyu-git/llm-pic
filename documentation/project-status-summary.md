## 🔧 开发环境配置

### 必需工具
- **Node.js**: >= 16.0.0
- **npm**: >= 8.0.0
- **现代浏览器**: Chrome, Firefox, Safari, Edge

### 开发命令
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 类型检查
npm run type-check

# 代码检查
npm run lint

# 代码格式化
npm run format

# 运行测试
npm run test
```

### 项目配置文件
- `vite.config.ts` - Vite 构建配置
- `tsconfig.json` - TypeScript 配置
- `.eslintrc.cjs` - ESLint 规则配置
